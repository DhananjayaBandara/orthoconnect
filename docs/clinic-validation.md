## Run optional interaction checks

The website has no runtime packages. To use an existing jsdom installation for checks:

```sh
ORTHOCONNECT_JSDOM_MODULE=/absolute/path/to/node_modules/jsdom node scripts/check_clinics_dom.cjs
ARTICLE_JSDOM_MODULE=/absolute/path/to/node_modules/jsdom node scripts/check_articles_dom.cjs
```

Where a browser and local sockets are available, serve the site in a separate terminal with `python3 -m http.server 8080 --bind 127.0.0.1`, then run:

```sh
ORTHOCONNECT_PREVIEW_URL=http://127.0.0.1:8080/ ORTHOCONNECT_PLAYWRIGHT_MODULE=/absolute/path/to/node_modules/playwright node scripts/check_homepage.browser.cjs
```

The browser check intercepts its two tested outbound booking navigations and returns test HTML; it creates no appointment and requires no patient information.
